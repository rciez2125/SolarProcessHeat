This repository includes some of the in-class examples for using pysam

gas_heat_model.py is a fully-functional model that supplies all heat using natural gas. You should incorporate solar resources into these models, using natural gas as a backup power source
run_gas_heat_model.py runs the model created in gas_heat_model.py, with specific values for input parameters

both the pv/heat battery and csp/falling particle teams should create branches from this repository to add their models
use Van Horn, TX as the project location
